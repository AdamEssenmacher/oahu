# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**, or go directly to <https://github.com/AdamEssenmacher/oahu/security/advisories/new>. Do not open a public issue or pull request for a vulnerability.

Include:

- The affected package and version, or the commit if you built from source.
- The operating system and target framework.
- What the vulnerability allows and under what conditions.
- Steps or a minimal project that reproduces it.
- Any fix or mitigation you know of.

## Supported versions

No packages have been released yet. Once packages ship, security fixes go to the latest release.

## What to expect

Oahu has a single maintainer. Reports are answered on a best-effort basis, with no guaranteed response time, and there is no bug bounty. Once a fix is released, the report is published as a GitHub security advisory, crediting you unless you ask not to be named.
